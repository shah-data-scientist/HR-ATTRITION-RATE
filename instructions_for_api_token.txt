To resolve the API token issue and get the application working, please follow these steps:

1.  **Create a `.env` file:** In the root directory of your project (C:\Users\shahu\OPEN CLASSROOMS\PROJET 5\HR Attrition Rate\), create a new file named `.env`.

2.  **Add your API Token:** Open the newly created `.env` file and add the following line:
    ```
    API_TOKEN="your_secret_token_here"
    ```
    Replace `"your_secret_token_here"` with any string you choose. This will be your API token. For example, you could use `API_TOKEN="my_dev_token"`.

3.  **Start the FastAPI application:** If it's not already running, open a new terminal in the project root directory and run the FastAPI application using Poetry:
    ```bash
    poetry run uvicorn api.app.main:app --host 0.0.0.0 --port 8000 --reload
    ```
    This will start the API server, typically accessible at `http://localhost:8000`.

4.  **Run the Streamlit application:** In another terminal, start the Streamlit app:
    ```bash
    poetry run streamlit run app.py
    ```

5.  **Enter the API Token in the Streamlit UI:** When the Streamlit app loads in your browser, you will see an input field labeled "Enter your API Token". Enter the *exact same string* you used in your `.env` file (e.g., `my_dev_token`).

Once these steps are completed, the Streamlit application should be able to communicate with the FastAPI backend and perform predictions without the API token error.
